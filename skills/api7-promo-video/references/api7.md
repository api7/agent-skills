# API7

Identify the actual subject before making copy: API7.ai (company), API7 Gateway
or API7 Enterprise Edition (gateway product). Do not call all API7 products
“APISIX.” AISIX/AI Gateway needs its own current product evidence; it is not an
automatic alias for API7 Gateway.

The included `assets/brand/api7.webp` is the official website header wordmark.
Keep its proportions and native colors. The traffic-flow starter uses #E8433E;
the approved AISIX authored-feed treatment uses #E31836 and the low-opacity
purple/red homepage pools detailed in [Approved feed style](approved-feed-style.md).
Keep the shared light ground and Inter typography. Consult the current official website
for a requested campaign's brand changes rather than inventing a new logo.

Source starting points: [API7](https://api7.ai/),
[Enterprise product](https://api7.ai/enterprise),
[Gateway docs](https://docs.api7.ai/api7-gateway/).
For AISIX, use the [AI Gateway docs](https://docs.api7.ai/ai-gateway/) and the
specific model, release or workflow page. Verify newly supported models against
the actual release/version. Typeset AISIX as the product name; the included API7
wordmark identifies the company and must not be labelled an AISIX product logo.
Verify a specific edition/version and feature against its actual documentation
before describing it. Capabilities, naming, plans and release information may
change; source links alone do not prove an uninspected claim.

Use real screenshots/recordings for UI-led stories. Crop to the meaningful panel
and enlarge it so labels can be read at phone size. Remove secrets and private
customer data. Do not rebuild an invented console or use the APISIX abstract
flow template as a substitute for proof of API7 administration features.

CTA selection:

- Feature configuration: the matching version-aware docs page.
- First-use introduction: the actual getting-started path for that product.
- Commercial evaluation: the current product demo/contact page, only when that
  is the film's intended next action.

Inspect the destination and verify it exists before delivery. Do not assume
that a historical URL, screenshot or pricing claim is still valid. Keep one CTA
across the film, cover description and post.
